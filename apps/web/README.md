# Веб-приложение «Арена переговоров»

Интерфейс на Next.js 15, React 19 и TypeScript. Здесь можно выбрать или сгенерировать сценарий, провести текстовые переговоры с AI-оппонентом, получить отчёт с оценкой и рекомендациями, повторить попытку и сравнить результаты. Для зарегистрированных пользователей доступны история тренировок, обучение и взаимная проверка. Диктовка использует распознавание речи браузера; для естественного голоса AI-оппонента нужен Gemini API на сервере.

## Локальный запуск

Понадобится Node.js 22 с npm. Сначала запустите API по инструкции в [корневом README](../../README.md), затем из корня репозитория выполните:

```powershell
cd apps/web
npm ci
npm run dev
```

Откройте <http://localhost:3000>. Если API недоступен, интерфейс показывает встроенные демонстрационные сценарии и отчёт; функции учётной записи и сохранение тренировок требуют работающего API.

## Подключение к API

По умолчанию браузер отправляет запросы на `/api/v1` того же сайта. Next.js перенаправляет их на `http://127.0.0.1:8000` через правило в `next.config.ts`. Если API работает по другому внутреннему адресу, задайте `INTERNAL_API_URL` в окружении процесса Next.js, например `http://127.0.0.1:8001`.

Публичная переменная `NEXT_PUBLIC_API_URL` позволяет изменить адрес API в браузере. При обычном локальном запуске она не нужна: оставьте её неустановленной, чтобы использовать прокси. Не передавайте через `NEXT_PUBLIC_*` API-ключи или другие секреты.

## Проверки

Из каталога `apps/web`:

```powershell
npm run typecheck
npm run build
node --test
```

Последняя команда запускает тесты из `tests/` на встроенном тестовом раннере Node.js.
