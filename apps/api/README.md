# API «Арены переговоров»

Backend на FastAPI и Python 3.12. API управляет сценариями и сессиями переговоров, сохраняет сообщения и результаты в PostgreSQL через SQLAlchemy, формирует отчёты и поддерживает взаимную проверку. Схему базы обновляют миграции Alembic.

## Локальный запуск

Пошаговые команды для PostgreSQL, миграций, API и интерфейса приведены в [корневом README](../../README.md#локальный-запуск). После запуска доступны [интерактивная документация API](http://127.0.0.1:8000/docs) и проверки `/health`, `/health/ready`, `/health/dependencies`.

Основные настройки задаются переменными окружения: `DATABASE_URL` — подключение к PostgreSQL, `GEMINI_API_KEY` — необязательный ключ Gemini, `GEMINI_MODEL` — модель для генерации, `CORS_ORIGINS` — разрешённые источники запросов. Пример значений находится в [`.env.example`](.env.example); поле ключа в нём пустое. При ручном запуске передавайте секреты через окружение процесса API, не добавляя их в Git.

## Как устроен API

| Часть | Назначение |
| --- | --- |
| `app/engine/` | Детерминированный движок: классификация реплик, проверка условий сделки, переходы состояния и директивы оппоненту. Его решения не зависят от Gemini. |
| `app/llm/` | Формулировка реплик и пояснений через Gemini с проверкой ответа. При пустом ключе, ошибке или тайм-ауте текстовый диалог использует резервные шаблоны. |
| `app/reporting/` | Оценка по пяти блокам рубрики с подтверждающими репликами и рекомендациями. Gemini не выставляет баллы. |
| `app/peer_review.py` | Анонимная взаимная проверка сессий; отзыв проверяющего не меняет автоматическую оценку. |
| `app/db/`, `alembic/` | Модели хранения и миграции PostgreSQL. |

Публикуемые конфигурации лежат в `scenarios/*.json`, методические эталоны — в `golden_dialogues/<scenario-id>/*.json`. Схемы форматов находятся в [`docs/schema`](../../docs/schema). Публичные ответы API формируются из разрешённых полей и не раскрывают скрытые интересы и пределы сторон.

Основные маршруты: `GET /api/v1/scenarios`, `POST /api/v1/sessions`, `POST /api/v1/sessions/{id}/messages`, `GET /api/v1/sessions/{id}/report` и `GET /api/v1/peer-reviews/next`. Полный список и модели запросов доступны в `/docs`.

## Тесты

Из каталога `apps/api` после создания виртуального окружения:

```bash
python -m pip install -e ".[dev]"
python -m pytest
```

Тесты проверяют движок и сценарии, отчёты, доступ к данным, миграции, Gemini и резервный режим.
